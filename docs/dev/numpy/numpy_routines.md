ルーチンとオブジェクト（トピック別）
===
この章では,ルーチンのドキュメント文字列を機能別にグループ分けして紹介します。多くのドキュメント文字列には,ルーチンの基本的な使い方を示すサンプルコードが含まれています。

サンプルを実行する便利な方法として,IPythonの`%doctest_mode`モードがあります。このモードでは,複数行のサンプルを貼り付けることができ,インデントも保持されます。
