# 正規表現 共通構文リファレンス

正規表現の書き方のmdファイル
ベースはPCRE(Perl互換正規表現)に準拠している

---

## 1. 基本のメタ文字

| 記号 | 意味                             | 例         | マッチする例          |
| ---- | -------------------------------- | ---------- | --------------------- |
| `.`  | 改行以外の任意の1文字            | `a.c`      | `abc`, `axc`          |
| `^`  | 文字列(または行)の先頭           | `^abc`     | 先頭が`abc`の文字列   |
| `$`  | 文字列(または行)の末尾           | `abc$`     | 末尾が`abc`の文字列   |
| `\|` | OR(またはどちらか)               | `cat\|dog` | `cat`, `dog`          |
| `()` | グループ化・キャプチャ           | `(abc)+`   | `abc`, `abcabc`       |
| `[]` | 文字クラス(いずれか1文字)        | `[abc]`    | `a`, `b`, `c`         |
| `\`  | エスケープ(メタ文字を通常文字に) | `\.`       | `.`という文字そのもの |

---

## 2. 文字クラス(`[]`)

| 記法        | 意味                       |
| ----------- | -------------------------- |
| `[abc]`     | `a`, `b`, `c`のいずれか    |
| `[^abc]`    | `a`, `b`, `c`以外の文字    |
| `[a-z]`     | `a`から`z`の範囲           |
| `[A-Z0-9]`  | 大文字アルファベットと数字 |
| `[a-zA-Z_]` | 英字とアンダースコア       |

---

## 3. 定義済み文字クラス(ショートハンド)

| 記法 | 意味                                   | 対応する文字クラス |
| ---- | -------------------------------------- | ------------------ |
| `\d` | 数字1文字                              | `[0-9]`            |
| `\D` | 数字以外の1文字                        | `[^0-9]`           |
| `\w` | 単語構成文字(英数字＋`_`)              | `[a-zA-Z0-9_]`     |
| `\W` | 単語構成文字以外                       | `[^a-zA-Z0-9_]`    |
| `\s` | 空白文字(半角スペース・タブ・改行など) | `[ \t\n\r\f\v]`    |
| `\S` | 空白文字以外                           | `[^ \t\n\r\f\v]`   |
| `\b` | 単語境界(境界そのもの,幅0)             | -                  |
| `\B` | 単語境界以外                           | -                  |

---

## 4. 量指定子(繰り返し)

| 記法                    | 意味                 |
| ----------------------- | -------------------- |
| `*`                     | 0回以上(直前の要素)  |
| `+`                     | 1回以上              |
| `?`                     | 0回または1回         |
| `{n}`                   | ちょうどn回          |
| `{n,}`                  | n回以上              |
| `{n,m}`                 | n回以上m回以下       |
| `*?` `+?` `??` `{n,m}?` | 非貪欲(最短マッチ)版 |

> **貪欲(greedy)と非貪欲(lazy)の違い**
> - `<.+>` → `<a><b>` 全体にマッチ(貪欲)
> - `<.+?>` → `<a>` だけにマッチ(非貪欲)

---

## 5. グループとキャプチャ

| 記法            | 意味                                               |
| --------------- | -------------------------------------------------- |
| `(abc)`         | キャプチャグループ(後で`\1`などで参照可能)         |
| `(?:abc)`       | 非キャプチャグループ(グループ化のみ,参照不可)      |
| `(?P<name>abc)` | 名前付きグループ(Python, .NET等)                   |
| `(?<name>abc)`  | 名前付きグループ(JavaScript, Java, PHP等)          |
| `\1`, `\2`      | 1番目・2番目のキャプチャグループを再参照           |
| `(?=abc)`       | 先読み(肯定) — `abc`が続く位置にマッチ(消費しない) |
| `(?!abc)`       | 否定先読み — `abc`が続かない位置にマッチ           |
| `(?<=abc)`      | 後読み(肯定) — 直前が`abc`である位置にマッチ       |
| `(?<!abc)`      | 否定後読み — 直前が`abc`でない位置にマッチ         |

> ⚠️ 後読み(`(?<=)` `(?<!)`)は言語によって「可変長」に対応していない場合があります(例: JavaScriptの古いエンジンでは非対応でした)。

## 6. アンカー・境界

| 記法 | 意味                                         |
| ---- | -------------------------------------------- |
| `^`  | 文字列(複数行モードでは行)の先頭             |
| `$`  | 文字列(複数行モードでは行)の末尾             |
| `\A` | 文字列全体の先頭(複数行モードでも変わらない) |
| `\Z` | 文字列全体の末尾(改行を許容)                 |
| `\z` | 文字列全体の末尾(厳密)                       |
| `\b` | 単語境界                                     |

---

## 7. よく使うフラグ(修飾子)

| フラグ | 意味                                                           | Pythonでの指定例 |
| ------ | -------------------------------------------------------------- | ---------------- |
| `i`    | 大文字小文字を区別しない                                       | `re.IGNORECASE`  |
| `m`    | 複数行モード(`^` `$`が各行に適用)                              | `re.MULTILINE`   |
| `s`    | `.`が改行にもマッチする                                        | `re.DOTALL`      |
| `g`    | グローバルマッチ(JS特有。Pythonでは`findall`/`finditer`で代用) | -                |
| `x`    | 拡張モード(空白・コメントを許可)                               | `re.VERBOSE`     |

---

## 8. 実用例(構文は言語共通,書き方の器のみ違う)

### メールアドレスの簡易チェック
```
^[\w.+-]+@[\w-]+\.[a-zA-Z]{2,}$
```

### 日本の郵便番号(例: 123-4567)
```
^\d{3}-\d{4}$
```

### HTMLタグの中身を抽出(非貪欲)
```
<(\w+)>(.*?)</\1>
```

### 数字のみの文字列
```
^\d+$
```

---

## 9. 言語ごとの違い(注意点)

| 項目             | Python (`re`)                    | JavaScript                 |
| ---------------- | -------------------------------- | -------------------------- |
| 名前付きグループ | `(?P<name>...)`                  | `(?<name>...)`             |
| グローバル検索   | `re.findall()` / `re.finditer()` | `/pattern/g`               |
| 複数行フラグ     | `re.MULTILINE`                   | `m`フラグ                  |
| Unicode対応      | デフォルトでUnicode対応          | `u`フラグが必要な場合あり  |
| 後読みの可変長   | 対応                             | 対応(比較的新しいエンジン) |

---

## 10. Pythonでの基本的な使い方(参考)

```python
import re

pattern = r"^\d{3}-\d{4}$"
text = "123-4567"

match = re.match(pattern, text)
if match:
    print("マッチしました:", match.group())
```

---

### まとめ
- `.` `^` `$` `*` `+` `?` `[]` `()` `|` `\` は**ほぼ全言語共通**の基本構文です。
- 違いが出やすいのは「名前付きグループの記法」「フラグの指定方法」「グローバル検索の方法」です。
- Python (`re`モジュール) では基本的にPCRE準拠のためこのリファレンスがそのまま使えます。
